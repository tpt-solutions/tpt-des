# tpt-des documentation

Guides for using the library. The API reference is generated by rustdoc:

```sh
cargo doc --workspace --all-features --no-deps --open
```

| Guide | Read it when |
|---|---|
| [Getting started](getting-started.md) | You are new to the library. |
| [Choosing a crate](choosing-a-crate.md) | You know the question, and want the right module. |
| [Validating a model](validating-a-model.md) | You need to show that a model is right. |
| [FAQ](faq.md) | A common question is not answered elsewhere. |
| [Spec versus implementation](status.md) | You want to know what the design promises and what is built. |
